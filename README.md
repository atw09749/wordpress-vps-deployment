## WordPress 到底需要什么：官方门槛和实际门槛差多少

WordPress 官方文档给的最低要求是 PHP 7.3+、MySQL 5.6+。这两个数字是"能装起来"的门槛，不是"跑得动"的门槛，而且早就过时了。

PHP 7.4 已经停止安全更新，市面上流传的"老主题老插件在 7.4 上更保险"这个说法，今天不该再当成选型依据。新建站点直接上 **PHP 8.2**，性能比 7.4 高出一截，主流主题和插件早就完成了适配。如果你手上有一个多年没更新的插件，问题出在那个插件，不该让整台服务器为它降级。

数据库方面，1GB 内存的机器不要碰 MySQL 8.0，它吃内存太猛，装到一半 OOM 是常见事故。选 MySQL 5.7 或 MariaDB 10.x 更稳，跑 WordPress 完全够用。字符集统一用 `utf8mb4`，中文、emoji、特殊符号一次解决，别用 `utf8`——那是个历史遗留的坑，它并不是真正的 UTF-8。

真正卡人的是内存。PHP-FPM 每个进程要占几十兆，MySQL 起步就是两三百兆，系统本身和 Nginx 再吃掉一百多。1GB 的机器留给 WordPress 的余量大概就是一两个 PHP 进程同时干活，访客一多就排队。这就是为什么"1GB 能跑"和"1GB 好用"是两句话。

## 路线 A：装面板，鼠标点完 LNMP

不会 Linux 命令、或者不想记命令的人，走这条。

**宝塔面板**的安装命令是一行：


wget -O install.sh https://download.bt.cn/install/install_lts.sh && sh install.sh ed8484bec


装完浏览器打开 `IP:8888`，进去点软件商店装 Nginx、MySQL、PHP，再进"一键部署"选 WordPress，填域名和数据库信息，几分钟站点就跑起来了。CentOS、Debian、Ubuntu 都支持。

**1Panel** 是另一条路子，开源免费、界面干净、Docker 原生支持，没有宝塔那些弹窗和绑定：


curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && bash quick_start.sh


安装两三分钟，面板端口是随机生成的，不再是默认的 8888，这一点比宝塔安全。之后在"网站"里创建站点，类型选 PHP，**PHP 版本选 8.2**，数据库字符集选 `utf8mb4`，根目录默认 `/opt/www/你的域名`。创建完成后把面板生成的数据库名、用户名、密码复制下来，装 WordPress 时要填。

两个面板都有一件事容易漏：端口要在**两个地方**放行。云厂商控制台的安全组是一层，面板自带的防火墙是另一层。22（SSH）、80（HTTP）、443（HTTPS）、面板端口，四处都要开，否则你会对着打不开的页面怀疑人生。

面板路线的代价是内存。宝塔本身要占两三百兆，1GB 的机器上再跑 WordPress，PHP 进程一多就顶到天花板。**1GB 配面板，是把两个挤在一起的东西硬塞进一个小房间**，能住，但别指望舒展。2GB 以上再考虑面板，1GB 老老实实走下面那条路。

## 路线 B：命令行，把每一层都看清

LNMP 一键包是命令行路线里最省事的：Linux + Nginx + MySQL + PHP，这套组合比 Apache 省内存，1GB 的机器跑起来没什么压力。

先开一个 screen 会话防止 SSH 断线把安装打断：


screen -S lnmp


然后下载并运行安装脚本：


wget http://soft.vpser.net/lnmp/lnmp2.0.tar.gz -cO lnmp2.0.tar.gz && tar zxf lnmp2.0.tar.gz && cd lnmp2.0 && ./install.sh lnmp


接下来会问你 MySQL 版本、PHP 版本，不知道选什么就一路回车用默认。编译安装要 **20 到 40 分钟**，取决于机器性能和网络，期间别关窗口。装完敲 `lnmp status`，看到 Nginx、MySQL、PHP-FPM 三个都是 running，环境就成了。

添加站点用 `lnmp vhost add`，按提示填域名，网站目录默认 `/home/wwwroot/你的域名`，**伪静态规则一定要选 WordPress**，SSL 那一步选 y 会自动申请 Let's Encrypt 免费证书。

建库语句：

sql
CREATE DATABASE wordpress_db DEFAULT CHARSET utf8mb4;
CREATE USER 'wp_user'@'localhost' IDENTIFIED BY '你的数据库密码';
GRANT ALL PRIVILEGES ON wordpress_db.* TO 'wp_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;


传 WordPress 用命令行最干净：


cd /home/wwwroot/example.com
wget https://wordpress.org/latest.tar.gz
tar -xzf latest.tar.gz --strip-components=1
rm latest.tar.gz
chown -R www:www /home/wwwroot/example.com
chmod -R 755 /home/wwwroot/example.com


浏览器打开域名走安装向导，**数据库主机填 `localhost`**，别填 IP。后台入口是 `你的域名/wp-admin`。

如果你想把 Apache、MariaDB、PHP 三块砖一块块垒起来、搞懂每个模块为什么要加载，那就走 LAMP 路线：`sudo apt install lamp-server^` 这个元包会自动处理三者的依赖顺序，避免先装 PHP 再装 Apache 时 mod_php 没被启用这种隐形故障。这条路适合已经从面板毕业、想穿透 GUI 看底层的人，代价是排查问题时你要同时看得懂 Apache 的 error.log 和 PHP 的日志。对绝大多数建站需求，Nginx 系（面板或 LNMP）是更主流的选择，别为了"正统"绕远路。

## 从 0 到上线，五个最容易卡住的地方

1. **域名解析没生效就装 WordPress**。这时候 WordPress 会把站点地址写成 IP，后面改起来要进数据库。等 DNS 生效（`ping 你的域名` 返回的是你的 VPS IP）再装。
2. **固定链接没设成"文章名"**。装完进后台 → 设置 → 固定链接，选"文章名"，保存两次。不设的话文章 URL 是一串 `?p=123`，伪静态规则白配。
3. **文件权限不对**。目录 755、文件 644、`wp-content/uploads/` 给 775，属主是 `www`（LNMP）或 `www-data`（LAMP/1Panel）。权限错了的表现是后台上传图片提示"缺少写权限"、装插件要你填 FTP 账号。
4. **MySQL root 密码找不到**。LNMP 装完密码存在 `/root/lnmp_soft/mysql_root_password`，`cat` 一下就能看。
5. **PHP 禁用函数拦住了插件**。有些面板默认禁用了 `proc_open`、`putenv`，不少正经插件要用这两个函数。按需放行，别一股脑全禁——安全性和可用性在这里要取舍。

## 装完了还是慢？按这个顺序查

页面慢的原因有优先级，从上往下查，别一上来就怀疑配置不够。

**先看缓存开没开。** 装 Redis Object Cache 插件，在 `wp-config.php` 里加一行 `define('WP_REDIS_HOST', '127.0.0.1');`，启用后看到 Connected 就成。再配一个页面静态缓存插件，让访客拿到的是 HTML 而不是每次现算的 PHP。这两层做与不做，差距是数量级的。

**再看图片。** 一张手机拍的原图五六兆，首页放三张就是二十兆，什么线路都救不了。装图片压缩插件，开 WebP 转换，上传前先自己压一遍。

**然后看 CDN 生效没有。** 域名接 Cloudflare 之后，`ping` 一下应该返回 Cloudflare 的 IP 而不是你的服务器 IP。SSL/TLS 模式选 **Full（严格）**，因为源站已经有证书了，选 Flexible 会绕成死循环。顺手开会 Auto Minify、Brotli、Always Use HTTPS，橙色云朵点亮。海外访客的打开速度会有明显变化，顺带挡掉一部分 DDoS 和 CC。

**接着数插件。** 后台启用的插件超过 10 个就该清一遍，每个插件都在消耗 PHP 进程时间。主题同理，Astra、GeneratePress 这类轻量主题代码干净，那些"功能一大堆"的多功能主题（Avada、The7 这一类）装上去就背着几十个脚本跑。

**最后才看服务器。** `top` 看 CPU 和内存，`free -h` 看剩余内存，如果内存长期贴着上限、swap 在频繁读写，那就是配置真的不够，该升档了。反过来，如果 CPU 和内存都清闲、页面还是慢，问题在网络或者前端资源，加钱买配置没用。

## 安全与备份，四个动作

改 SSH 端口，禁用密码登录改密钥——爆破攻击每天几万次，改端口能挡掉九成。

装一个登录限流插件，输错 5 次密码封 IP 一小时。WordPress 的登录页是最常被撞的地方。

后台用户名不要用 `admin`，密码 12 位以上，大小写数字符号混着来。

开每日自动快照，保留 7 天；WordPress 数据另外用备份插件每周同步到云端。快照能救回服务器，救不回你手滑删掉的文章，两者都要。

## FAQ

**1GB 内存到底能不能跑 WordPress？**
能，这是底线。不装太多插件、不上 WooCommerce 的情况下，日常访问没问题。但只要装上缓存插件、安全插件、SEO 插件、表单插件这一套标配，余量就所剩无几了。预算允许就上 2GB。

**面板和命令行，选哪个？**
不会 Linux 就面板，1Panel 比宝塔干净。1GB 内存的机器选命令行，面板会把本来就不多的内存再分走一块。想把每一层都搞明白，走 LAMP，但要知道这条路排查问题更花时间。

**WordPress 需要什么 PHP 和 MySQL 版本？**
官方最低要求是 PHP 7.3+、MySQL 5.6+，但那是历史口径。新建站点用 **PHP 8.2 + MySQL 5.7 或 MariaDB 10.x**，字符集 `utf8mb4`。1GB 内存不要装 MySQL 8.0。

**服务器 IP 被墙了怎么办？**
开通后第一时间 `ping` 一下 IP。连不上就开工单让客服换 IP，别等到站点配好了才发现。这是概率问题，不是商家的问题，但处理速度差别很大。

**月付还是年付？**
年付折合月价便宜很多，代价是锁死。第一次用某家商家，先月付或者用试用跑一周，确认线路和稳定性符合预期，再考虑长期。反过来，如果已经确定这台机器要长期跑，年付的折扣是实打实的。

**站点给国内用户看，机房怎么挑？**
看回程线路，不看机房地理位置。三网 CN2 GIA 的机器晚高峰不会突然卡住，普通国际线路的机器白天测试好看、晚上八点开始丢包。买之前问清楚线路类型，或者用试用期在晚高峰自己测一遍。
